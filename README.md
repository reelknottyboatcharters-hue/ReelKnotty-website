# Reel Knotty Boat Charters — Website

The public website for Reel Knotty Boat Charters, served at
**reelknottyoutfitters.com**.

- Built with Muse, stored here in GitHub, and pulled live by the host's
  server whenever this repo changes.
- Pages: Home, Trips & Rates, About the Captain, Photos, Contact.
- Booking works both ways: call/text Rich at 646-261-6400, or book online
  via the booking page linked on the site.
- 2027 beach charter: $850, up to 10 people, hot dogs and hamburgers
  included. $200 deposit holds a date. Wagyu package (2 steaks) +$200.
  Fishing charters: 6 people, call for rate.

To change anything, edit the HTML/CSS files and push — the live site
updates within a minute or two.
